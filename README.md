# Forum App — HUGBUNADARVERK2

A Reddit-style Android community discussion app built with Kotlin and Jetpack Compose.

## Requirements

- Android Studio Hedgehog (2023.1.1) or newer
- JDK 17
- Android SDK — compile SDK 35, min SDK 24 (Android 7.0+)
- An Android device or emulator running Android 7.0+

## How to Build & Run

1. Clone the repository
   ```bash
   git clone <repo-url>
   cd hugbunadarverk2
   ```

2. Open in Android Studio
   File → Open → select the `hugbunadarverk2` folder

3. Let Gradle sync — Android Studio will automatically download all dependencies. Wait for the sync to complete.

4. Run the app
   - Connect a physical device via USB, or start an emulator
   - Press the green Run button

### Build from the command line

```bash
# Debug build
./gradlew assembleDebug

# Install directly to connected device
./gradlew installDebug
```

The APK will be output to `app/build/outputs/apk/debug/app-debug.apk`.

## API Keys & External Services

No API keys are required. The app connects to a backend hosted on Render.com:

```
https://hugbunadarverkefni1-1.onrender.com/
```

This URL is hardcoded in `app/build.gradle.kts` as a `BuildConfig` field.

Note: The backend is hosted on Render's free tier, so the first request after a period of inactivity may be slow (cold start).

## Local Configuration

The file `local.properties` is auto-generated by Android Studio and contains your local Android SDK path.
